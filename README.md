# مُحاسب

موجّه يومي للمحاسب المبتدئ: مطابقة مبيعات اليوم (نقد، شبكة، تحويل، آجل)، موجّه العمليات والقيود، أخطاء المبيعات، الأصناف بالسالب، الأستاذ العام، وقوائم الإقفال.

- افتح `index.html` في المتصفح مباشرة، لا يحتاج خادمًا.
- المصدر في `src/app.html`، وبعد تعديله شغّل `./build.sh`.
- أسماء الشاشات عامة وليست مأخوذة من دليل «المحاسب الشامل بلس».
